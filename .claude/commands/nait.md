---
description: The NAIT round: cattle and deer movements, due dates and which are recorded, late or overdue.
---

Run `npm run farm -- nait --json`.

Lead with DUE (still inside 48 hours) and OVERDUE. For each give mob, reference, the other NAIT location and the last day. When the operator says it is done in NAIT, run `nait-recorded <reference>`.

Read live records before answering. Name the records and dates. If a figure is missing, say missing. Nothing sends.
