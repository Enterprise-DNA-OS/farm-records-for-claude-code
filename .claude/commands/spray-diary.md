---
description: The spray diary: product, rate, target, operator, wind and grazing withholding.
---

Run `npm run farm -- spray-diary --json`.

Flag any record missing rate, operator, wind or withholding. Record a new one with `spray "<paddock>" --product=... --rate=... --operator=... --wind=... --whp=<days>`, which puts the paddock on a grazing hold.

Read live records before answering. Name the records and dates. If a figure is missing, say missing. Nothing sends.
