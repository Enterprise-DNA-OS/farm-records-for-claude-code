Run `npm run farm -- incidents --json`.

Lead with notifiable events that have no WorkSafe reference. Record one with `incident --name=... --what=... --by=... [--notifiable]`. Whether an event is notifiable is the operator's call.

Read live records before answering. Name the records and dates. If a figure is missing, say missing. Nothing sends.
